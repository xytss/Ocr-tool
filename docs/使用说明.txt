OCR 工具
========

系统要求
--------
Windows 10/11 x64。

绿色版
------
1. 解压完整压缩包。
2. 运行 OcrTool.App.exe。
3. 不要只复制 EXE；models 和其他 DLL 都是运行所需文件。

安装版
------
双击下载的 MSI 文件，按照 Windows Installer 提示完成安装。
安装到 Windows 标准 Program Files 目录，安装时需要确认管理员权限。

使用方法
--------
1. 默认按 F2 开始截图 OCR。
2. 拖动鼠标框选文字区域，松开后开始识别。
3. 结果窗口左侧显示原图，右侧文字可以编辑和复制。
4. Esc 或鼠标右键可取消截图。
5. 右键托盘图标可打开设置或退出。

设置
----
- 自定义截图快捷键。
- 选择是否显示识别结果窗口。
- 选择是否自动复制识别文字。
- 选择是否登录 Windows 后自动启动。

隐私
----
图片识别完全在本机完成，不会上传截图或识别文字。

文件说明
--------
绿色版的 settings.json 在首次保存设置后生成于解压目录。
安装版的 settings.json 保存在当前用户的 LocalAppData\OcrTool 目录。

提示
----
当前发布包未进行商业代码签名。Windows 可能显示“未知发布者”或 SmartScreen 提示，
这是签名状态提示，不代表 OCR 内容会上传。
